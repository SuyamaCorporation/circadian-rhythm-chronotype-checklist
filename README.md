# 概日リズム・クロノタイプ診断チェックリスト

MEQ（朝型夜型質問紙）ベースの19問診断でクロノタイプを判定し、最適な生活時間帯を提案するツール。

## 機能

- MEQ準拠19問（各5択）ステップ表示
- スコア集計 → 超朝型 / 朝型 / 中間型 / 夜型 / 超夜型の5タイプ判定
- 推奨睡眠・活動・食事・運動時間帯の表示
- 24時間円グラフ風SVGスケジュール表示（睡眠帯・集中帯を色分け）
- 生活改善チェックリスト（タイプ別5項目）
- localStorageに結果保存・次回起動時自動復元

## 技術仕様

- バニラJS / Tailwind CDN / インラインSVG
- XSSガード実装済み（escHtml関数）
- レスポンシブ対応
- 全インタラクティブ要素にaria-label付与
